## 🐛 Fixes

- Redact the host-collector run diagnostic sidecar

  Under `mode: local`, the `router-metrics` host collector writes a `<name>-info.json`
  diagnostic sidecar containing the full process. environment of the machine
  `collect.sh` ran on. This is now redacted in full.

  Narrows what's captured in the first place with `ignoreParentEnvs: true` (clears the
  command's env to just `PATH`/`KUBECONFIG`/`PWD`) and adds a redactor that masks the
  sidecar wholesale regardless. Covered by a chainsaw assertion in every `mode: local`
  e2e test (`official-chart`, `raw-manifest`, `multi-release`,
  `official-chart-metrics-no-servicemonitor`) that the sidecar is present and fully
  redacted.
